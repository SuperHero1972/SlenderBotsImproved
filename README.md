# SlenderBots
Play SF2 with Bots - now compatible with all maps!

A slightly improved version of TehPlayer14's plugin, removing the previous hardcoded map restrictions and subsequently allowing the bots to traverse any map.
## Reqiurements
A server running Slender Fortress 2. Works best with [Version 1.7.5,](https://github.com/Mentrillum/Slender-Fortress-Modified-Versions/releases/tag/v1.7.5.10mod) but confirmed to also work with [Mentrillum's 1.8.0 rewrite branch.](https://github.com/Mentrillum/Slender-Fortress-Modified-Versions/pulls)

[Latest version of TF2Attributes, found here.](https://github.com/FlaminSarge/tf2attributes)

## Installation
This guide assumes you have already successfully installed SourceMod and TF2Attributes.
### Method 1
PREFACE: You must be comfortable with compiling with SourceMod's compile.bat
1. Download the latest slenderbots.sp file
2. Drag the file to your server's scripting folder (tf/addons/sourcemod/scripting)
3. Run SourceMod's compiler. If successful, drag slenderbots.smx to your plugins folder (tf/addons/sourcemod/plugins)
### Method 2
If you're not comfortable compiling or don't feel arsed, download slenderbots.smx and simply drag it to your plugins folder. (tf/addons/sourcemod/plugins)

I reccommend compiling it on your own, as the .smx file is unlikely to be updated.
